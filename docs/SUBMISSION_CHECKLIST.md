# Submission checklist

## Source package: included

- Complete FastAPI and React source, including batch processing.
- README with local setup, run, tests, and live-mode configuration.
- Approach, tools, assumptions, regulatory boundaries, and security notes.
- Controlled test labels and a usable CSV template/sample.
- Python, JavaScript, and browser acceptance tests with executed local evidence.
- Docker, Render, and GitHub Actions configuration.
